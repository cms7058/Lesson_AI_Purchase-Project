# VTable 甘特图与项目助手

本阶段接入 `@visactor/vtable-gantt`，保持 Vue 2。项目工作台的“项目甘特图”展示任务、负责人、部门、日期和依赖线。鼠标拖动通过 `/projects/schedule-preview` 联动后续任务，需保存项目才持久化。组件数据使用副本，失败后恢复原计划。当前工期拉伸、连线编辑和进度拖动关闭，使用任务明细编辑并经后端校验；不包含关键路径或资源平衡引擎。

浮动助手移除全部预置快捷标签，保留清空与发送。项目对话支持项目编号/完整名称、项目状态、逾期任务、里程碑、负责人展示、上下文追问及状态图表和分页。项目进度为任务进度简单平均，预算不是实际成本。查询范围遵循有效项目授权；供应商不会进入项目查询。项目回答目前为数据库驱动的本地规则分析，不是专有模型训练，不执行计划修改或发送通知。

验证：后端 153 项测试通过；`apps/web/tests/gantt-access-real.e2e.js` 使用独立 SQLite 服务，实际鼠标拖动两天、检查后续任务日期、保存回查、人员授权/撤销，并在浮动助手输入项目问题回车查看数据和 Canvas 图表。生产构建仍有体积警告。npm 报告依赖安全告警，未进行跨版本自动强制升级；云端上线前仍需专项处理。
