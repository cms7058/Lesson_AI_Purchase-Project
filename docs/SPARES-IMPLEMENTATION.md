## 已确认范围

以 ABC/VED/FSN 分类和多因素 TOC 驱动备件采购需求计划。不得建设库存记账、库位、盘点、收发料模块，也不设独立备件驾驶舱；后续统计必须并入采购驾驶舱，并支持全部/生产件/备件统一过滤。

## 本阶段已实现

- `/spares` 页面与 `/api/v1/spare-plans` 草稿 CRUD、分页和编码筛选。
- 复用已有有效物料编码，填写分类及依据、数据时点、需求日、规划期末、外部可用库存/在途、目标储备和预算。
- VED 风险上限显式配置，不预置行业标准；校验 V≤E≤D。
- 多方案 TOC 费用分解、数量/到货/风险/预算硬约束、无可行解说明、最低可行 TOC 推荐。
- 输入更改提示结果失效，保存时服务端重新测算；版本校验防止旧页面覆盖。
- 页面明确标注为人工参数测算，不宣称自动预测、回归训练或审批完成。
