# 询价定标与外部供货反馈分析

## 查看入口

- 询价项目 → 定标：选择“最低价中标”或“TOC分析定标”。旧“智能分析 → 物料采购成本分析”菜单已移除，旧网址跳转询价项目；历史数据库与兼容接口保留。
- 供应商管理 → 查看物料供货指标，或供应商行“按物料查看指标”：按供应商编码、物料编码显示四项指标的批次中位数，点击可展开原始数据与统计图。
- 系统配置 → 数据与API：点击“反馈接入说明 / 模板 / 数据”，或连接器行“供货反馈接入”。可下载CSV模板、查看字段字典和JSON示例、生成专用推送令牌、手工导入反馈数据。

## 定标口径

本版本按整张询价单选择一家供应商，不拆分物料授标。只比较该询价已关联的回标，不查询其他询价报价；要求物料范围、数量、单位和币种一致，重复物料行需先合并。缺少报价的供应商仍显示为未回标，不被当作零报价。

最低价金额为含税货款加本次报价中的物流费。TOC是对满足询价合格品数量目标的预计成本：

`预计TOC = (报价金额 + 询价数量 × 历史单位收货附加费用中位数) / 历史合格品率中位数`

附加费用为返工、延期、其他费用减退款/索赔；当前报价物流已计入，因此不再次叠加历史物流费。历史批次用于解释实际单位成本时，使用当批真实物流费。

每个物料至少需要3个同供应商、同物料、同币种、同单位、全批质检完成且费用已确认的批次。缺失数据不补0；合格品率中位数为0、退款导致预测负成本等情况标为数据不足/不可比较。零合格品批次仍保留用于合格率统计，不剔除失败批次。

只有所有有效回标均具备完整成本历史时才开放TOC整单定标，避免将缺少数据的供应商直接排除而形成偏置排名。并列最低可选择其一。最终确认时后端重新计算推荐结果，不能通过修改前端参数选择不符合规则的报价；保存本次分析快照和定标方式。

回归采用历史含税单价为X、历史单位合格品综合成本为Y的一元线性拟合。每供应商/物料至少5个可计算成本批次、价格有变化才画拟合线，并显示方程和R²。零合格品批次没有有限单位成本，不进入回归，但不从合格率统计剔除。回归用于诊断历史关系，不表示因果、不替代当前报价，也不会在没有数据时伪造曲线。

## 供应商指标

供应商档案不再允许手工写入合格率、交付率和服务分。旧数据库列为历史兼容保留，但不作为新的按物料指标数据来源。

| 指标 | 每批计算方式 | 方向 |
| --- | --- | --- |
| 质量合格率 | 合格数量 ÷ 检验数量 × 100% | 越高越好 |
| 准时交付率 | 准时到货数量 ÷ 收货数量 × 100% | 越高越好 |
| 返工率 | 返工数量 ÷ 检验数量 × 100% | 越低越好 |
| 服务响应时长 | 外部反馈的实际响应小时 | 越低越好 |

表中显示各批指标的中位数（不是按数量加权的总体合格率），明细同时显示均值、样本标准差、有效/缺失样本数。图形包含频率密度直方图与正态参考曲线、Q-Q图、最小值/Q1/中位数/Q3/最大值箱线图。

Shapiro-Wilk检验使用3—5000个有效样本，p<0.05拒绝正态假设。样本不足或方差为0时不强行检验；未拒绝正态不等于证明正态，百分比有界且可能并不服从正态分布。当前读取最近5000条匹配反馈，适合本地分析；大规模生产数据需要按业务期间聚合与归档。

## 外部对接与文件导入

1. 新建ERP/MES/WMS/QMS等连接器并启用。
2. 在其“供货反馈接入”生成专用令牌，只显示一次，后端仅保存SHA-256哈希。令牌轮换立即使旧值失效。
3. 外部系统向 `/api/v1/integration-feedback/{connector_id}` 主动POST标准JSON，认证头为 `Authorization: Bearer <专用令牌>`。令牌仅适用于该连接器，不使用员工演示角色头。
4. 每批1—1000条记录。系统侧先将订单、质检、到货与服务记录整理成统一批次字段；系统提供字段说明和请求示例，但不包含SAP/用友等厂商的现成字段转换器，也没有后台主动轮询ERP。
5. 手工导入使用下载的UTF-8/BOM CSV表头，最大5MB、1000行。CSV可在Excel中填写后以UTF-8 CSV保存。当前不直接解析xlsx文件。
6. 供应商编码与物料编码必须已存在，业务日期格式为YYYY-MM-DD；未知检验/响应数据留空，不填0代替缺失。
7. 成本默认未确认，只有完整质检、价格明确且 `costs_confirmed=true` 时纳入TOC。填写true表示提交方已核对所有费用（未发生的费用可以为0）。
8. 同连接器内 `external_id` 唯一。完全相同内容重复推送会跳过；同ID不同内容或任意行校验失败，整批回滚，不覆盖原始记录。修正来源数据需先采用受审计的更正流程，不能为同一批次任意更换ID反复导入以免重复计数。
9. 已有反馈的供应商、物料、连接器不允许删除；连接器可停用。来源记录与导入数量留痕。

生产对接需使用HTTPS、保护令牌并限制网关请求体大小。现有员工管理端仍是开发演示身份体系，不能因此整体公开8000/8080端口。外部ERP推送仅需放行专用接入路径，不应开放其他管理API。

## 演示数据与验证

已增量导入3家模拟供应商、2个物料、144批模拟反馈，以及询价 `DEMO-FB-RFQ`（标题“【模拟】最低价与TOC供货成本对比”）。物料编码为 `DEMO-FB-M001`、`DEMO-FB-M002`。演示数据不发送邮件、不覆盖原业务数据。

统计默认排除模拟数据。打开TOC或指标分析后勾选“包含模拟数据”即可查看。包含模拟数据时禁用正式TOC定标；后端正式计算始终排除模拟反馈。最低报价为供货商1，而演示TOC较低者为供货商2，可直观看到质量与附加费用的影响。
