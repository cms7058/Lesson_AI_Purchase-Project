# 询价在线回标与供应商门户

## 操作顺序

1. 在「供应商管理」维护供应商邮箱，并将符合条件的供应商设为已准入。
2. 系统管理员在「供应商管理 → 供应商账号与登录网址」为供应商创建登录名和至少 12 位密码，通过安全渠道通知供应商。可停用账号或重置密码；保存账号时旧登录会话失效。该入口、账号列表、登录网址及维护接口仅管理员可访问，采购经理、采购员、分析员、审计员均不可访问。系统配置中的独立账号菜单已移除，旧地址跳转至供应商管理。登录网址读取已保存的门户设置，未配置时使用当前站点的 `/supplier`。
3. 在「系统配置 → 邮件发送设置」配置 SMTP 主机、端口、加密方式、登录账号、授权码、发件邮箱、供应商可访问的门户 URL。启用“发布后自动发送”。未配置时发布不会发送邮件，仍可在门户报价。
4. 创建询价，保存后在「报价/附件」上传附件，再发布。每个附件最大 10MB；发布后询价范围与附件锁定。
5. 供应商访问 `/supplier`，登录查看受邀询价、下载附件，填写每项单价/税率/物流费和交期后提交。提交成功后自动创建报价并关联原询价，不需要采购员登记回标。
   在「我的报价附件」可上传盖章报价单、技术说明等（单文件10MB、每份报价最多20个）。提交前可删除；提交后附件与报价一并锁定，可在报价历史中下载。采购方在回标详情展开相应供应商即可下载已提交的报价附件，不能查看供应商尚未提交的附件草稿。供应商之间不可相互下载报价附件。
6. 采购端显示 `已回标数/邀请数`（如 `2/3`），点击查看每家供应商状态、报价明细与邮件发送结果。页面每 15 秒刷新，也支持手动刷新。询价项目内选择已回标报价定标。

供应商只看到自己的受邀项目与报价，不能查看竞争对手名单、报价和定标报价 ID。报价提交一次后不可自行修改；截止日期按北京时间当日结束处理，截止后/定标后拒绝报价。会话有效期 8 小时，连续密码错误 5 次锁定 15 分钟。

旧 `/quotations` 前端地址重定向至询价项目，导航与模块卡片已移除独立报价入口。原报价数据保留用于历史成本分析，未按物料或供应商擅自推断历史报价所属询价。旧录入/登记 API 仅为兼容已有数据与集成保留；新门户流程不调用它们。

## 邮件可靠性与密码

- 新发布询价按受邀供应商建立持久化邮件任务；启用自动发送时由后台任务发送。
- 成功记录不重复发送；失败/待发送可通过询价列表「发送/重试邮件」补发，补发时会重新读取供应商邮箱。
- SMTP 提交成功标记为已发送，不代表收件人已阅读或收件服务器最终投递成功。
- 进程在 SMTP 发送中退出可能留下 `sending` 状态，需要管理员核对邮件服务端记录再处理，不能盲目重发以免重复通知。此版本不是具备分布式恢复能力的邮件队列。
- SMTP 授权码通过 Fernet 加密保存，接口不回显；留空保持原值。默认加密密钥存于后端工作目录 `.mail-secret.key`，权限 0600；生产应通过 `PEBS_SECRET_KEY` 注入 Fernet 密钥并安全备份。迁移数据库时必须同时保留密钥，否则无法解密授权码。
- 邮件里的门户地址不能用 localhost 对外邀请；应使用部署后的 HTTPS 地址。邮箱密码不会出现在邀请邮件中。
- 现有“自动化工作流”的通用邮件发送仍使用原环境变量 SMTP 配置，本页面设置用于询价邀请；不要把两个通知通道混为一谈。

## 部署安全边界

当前采购管理端仍使用原有开发演示身份头，不具有面向公网的员工登录认证。**禁止直接将 8080/8000 整体暴露给外部供应商。**

正式接入供应商时应将管理端留在内网/员工认证网关后，在独立公网域名仅开放供应商页面与 `/api/v1/supplier/` API，并阻断其余 API、API 文档和静态业务文件目录。参考 `deploy/supplier-public.nginx.conf.example`，上线前替换域名、证书、静态目录、代理地址并进行部署验收。前端隐藏菜单不是后端权限边界。

询价附件保存在 `private_rfq_attachments/`，不静态公开；供应商下载时校验邀请关系。文件以下载方式返回、限制扩展名及大小；尚未接入病毒扫描，生产应补充恶意文件检测和反向代理请求体限制。
