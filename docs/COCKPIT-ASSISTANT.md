# 采购驾驶舱与全局助手

## 驾驶舱

- 时间联动：点击趋势月份或月份下拉选项，采购总额、采购员金额饼图、物料号金额饼图及明细同步切换；月份可反复切换，清空月份恢复日期范围。
- 三维柱状图：X轴月份、Y轴责任采购员、Z轴税前订单金额，支持旋转和缩放。显示所选月份及所选采购员；采购员饼图保留该月所有人员，支持继续点击切换。需要浏览器支持 WebGL。
- 物料饼图按一级分类汇总，点击下钻二级、三级，支持返回上级；末级点击选择该分类的趋势。未建立分类关系的订单物料单列“未分类”。分类金额沿父级汇总，各层级独立核对，不能将三个层级相加。
- 分类和采购员趋势保留日期范围以供跨月比较；三维图及下方统计使用所选月份。时间口径为订单创建日期。

- 月度金额、订单状态、供应商金额、采购员订单数量/金额、采购员供应商交付及时率五组图表。
- 点击月份、状态、供应商、采购员，会联动全部指标、图表和分页订单明细；支持日期、币种筛选及重置。
- 金额为订单税前金额，排除取消订单，不代表付款支出，不跨币种合计。
- 采购经理/管理员可在明细中“指定采购员”。新增 `order_buyer_assignments` 表，不改写历史创建人、不自动给历史订单分配责任人。
- 未指定订单单列；更改责任人会影响该订单的当前责任统计，写入审计日志。指定责任人不授予物料采购权限。
- 及时率 = 准时已收货批次 / 可评价已收货批次。实际收货日期与订单对应物料承诺交期比较；草稿收货、无交期、多交期无法唯一关联的批次排除。无样本显示“暂无数据”，不是零。
- 可展开采购员—供应商明细，查看已收货、可评价、准时批次。尚未到货的逾期订单不在该已收货及时率分母内。外部反馈目前没有订单关联字段，因此不能据供应商名称将其强行算到某个人。
- 订单编辑表单已增加承诺交期。生产部署需要为新增归属表建立正式迁移；开发环境沿用现有 create_all 增量建表。

## 全局助手

- 工作台菜单已移除助手入口，保留全局浮动按钮。
- 对话发送最近12条上下文，支持基于前一轮查询对象追问状态条件；分页继续使用已解析查询。回答完成后定位文字正文。
- 常见采购说明、TOC解释及查数结果摘要支持本地文字回答；配置大模型后会携带上下文请求文字解释，超时或空回答回退本地结果。未配置大模型时不是开放域通用聊天，复杂问题仍需要更具体的业务条件。

- 任意页面右下角打开浮动助手；内部页面切换后保留当前浮动窗口的会话；刷新浏览器清空，不写浏览器持久存储。
- 支持订单、询价、供应商、物料、报价价格、人员、采购分类授权。真实分页表格和匹配记录的分组统计图，不执行模型生成的 SQL。
- 示例：`查询本月待送货订单`、`查询订单 供应商名称：华东维修供应商 币种：CNY`、`查询物料编码 MAT-001 的价格`。
- 当前是白名单规则解析，不保证理解任意复杂自然语言。已识别条件明确展示，支持在结果中用组合条件编辑器补充/修正；价格明细保留币种、单位和税率，不将不同物料/单位价格混合平均。
- 图表统计全部匹配记录的前20个分组，不是当前页。查询不会自动修改模型、批准订单或修改人员权限。
- 人员及授权查询仅管理员/采购经理可用；供应商登录状态下仅可查询本企业已发布订单和受邀询价，不能查其他供应商或内部人员数据。
- 内部身份仍沿用现有开发用请求头机制，不能代替生产登录认证。

## 验证

- 后端：`cd apps/api && .venv/bin/pytest -q`。
- 前端：`npm --prefix apps/web run lint`、`npm --prefix apps/web run build`。
- 浏览器：`apps/web/tests/cockpit-assistant.e2e.js`，覆盖联动、分页、跨页浮动会话、七类查询、供应商登录提示及弹窗宽度。
