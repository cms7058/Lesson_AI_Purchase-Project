# 组合查询、采购状态与询价演示数据

## 使用

各业务列表顶部“组合查询”可添加最多 12 条 AND 条件。多页签页面先选择查询对象，系统会切换到对应页签并回到第 1 页。分页继续保留条件；切换菜单后清空。原有关键词、状态筛选与新增条件共同生效。表单的引用数据选择项不受列表筛选影响。

字段由后台公开白名单与数据库类型确定：文本支持包含/等于/不等于；数值和日期支持等于/不等于/上下限；布尔值使用是/否。区间添加两条上下限条件。状态可选中文选项，也可输入实际状态码。密码、令牌、存储路径及原始 JSON 内容不可查询。

覆盖采购订单、询价、申请、合同、报价兼容接口、供应商/物料/工厂、收货/质检/退货、对账/发票/付款、模板、连接器、预测/寻源/路径/报告、审计、人员/采购授权、供应商分类关联、工作流定义/执行/通知，以及供应商账号、供货反馈记录和供应商门户受邀询价。指标统计和询价分析弹窗仍使用其专用物料/供应商筛选；编辑表单明细和字段说明表不是数据库列表。

物料分类树按数据库条件查出匹配节点，并保留上级节点以维持树结构；分页计数按保留后的根节点计算。图表是全量概览，不随列表条件变化。

## 后台约定

`GET /api/v1/orders?page=1&page_size=10&filters=...`

filters 是 JSON 数组，例如：

```json
[
  {"field":"supplier_name","op":"contains","value":"精密"},
  {"field":"material_code","op":"eq","value":"MAT-001"},
  {"field":"status","op":"eq","value":"supplier_confirmed"},
  {"field":"created_at","op":"gte","value":"2026-01-01T00:00:00"}
]
```

`GET /api/v1/list-filter-schema` 提供字段字典。请求级 SQLAlchemy 过滤器只作用于注册的 GET 列表，在数据库 count、offset、limit 前生效，退出请求即移除，不改动写接口。关联物料字段使用 EXISTS，同一明细关系的多个条件要求同一行满足；返回单据仍包含完整明细。无效字段、运算符、日期、非有限数值返回 422。供应商门户不提供其他供应商字段，保持原有邀请范围和登录权限。

## 采购状态与质量追溯

- 供应商确认对应“待送货”（`supplier_confirmed`）。
- 已收货但尚未检完，或有未完成退货的不合格数量：质量追溯（`quality_tracking`）。
- 已检合格但未满足全部订单数量：部分送货（`partially_delivered`）。
- 所有物料合格交付数量达到订单数量：完成（`completed`）。
- 收货后这些状态自动计算，不能手工覆盖成草稿或完成。已取消订单不能恢复。
- 质量追溯按钮分页查看该订单关联的收货、质检、退货；支持分批检验，已完成退货释放补货容量，补货合格后可完成。

历史状态同步脚本：`apps/api/scripts/backfill_order_status.py`，默认仅预览；备份后加 `--apply` 才写入，并记录审计。当前本地数据库同步前备份：`/tmp/pebs-before-order-status-20260904-1542.db`。

## TOC 模拟数据

定标窗口顶部“查看正态分析图”可直接定位图表。按供应商、物料、指标切换，支持单位合格品综合成本、质量合格率、准时交付率、返工率、响应时长。默认显示实际分布/正态参考曲线与中位数箱线图；展开可查看 Q-Q 图及分页原始批次。显示样本数、均值、中位数、标准差和 Shapiro-Wilk 检验结果；无数据或常量样本不伪造正态曲线。

进入 TOC 定标分析时默认加载已有模拟批次。如果当前询价数据不足或关联报价无效，自动展示独立的完整演示案例，并明确显示原询价的数据问题与“不是当前询价实际分析”提示。切回最低价模式恢复当前询价；独立演示结果无法提交定标。界面统一使用 TOC，既有接口字段 `tco` 保留兼容。

询价定标窗口选择“TOC分析定标”，点击“生成当前询价模拟数据”，确认后为已经回标的供应商/物料生成 18 批演示历史，自动勾选包含模拟数据并展示成本与回归图。重复点击不重复生成。不新增虚假回标，不改报价，不发送邮件。尚无回标的询价需先报价，或查看专用演示询价 `DEMO-FB-RFQ`。

所有生成批次都标记 `is_demo=true`，真实统计默认排除；正式定标后台重新计算并排除模拟记录。前端处于模拟模式时禁用正式 TOC 定标。模拟数据不能作为实际采购决策证据。
