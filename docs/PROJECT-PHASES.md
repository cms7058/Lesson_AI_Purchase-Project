# 项目与采购平台实施记录

## 第一阶段：已实现

- `/projects` 项目工作台，编号/名称/状态查询及分页；项目草稿新增、编辑、删除。
- 工作包、任务、里程碑；负责人来自现有共享人员档案，不新建独立人员库。
- 日期和进度录入、上级及前置关联、循环校验；乐观锁防止旧版本覆盖。
- 基础甘特图显示当前编辑计划，尚无拖动排程、关键路径、日历和基线比较。
- 草稿发布前检查经理及任务负责人/日期；完成状态要求任务100%。
- 已发布项目的手动站内逾期检查，按Asia/Shanghai业务日期，不发送邮件。
- MSP UTF-8 XML上传形成项目草稿，保留源UID和任务日期/层级；高级约束、时滞、资源、基线、日历需人工复核。
- 统一PEBS AI助手入口，可查询项目概览和原有采购数据；项目筛选和修改暂未支持。
- 项目操作和查询暂限现有admin/procurement_manager角色，未实现项目成员级数据权限。

项目新增独立`managed_projects`表，任务以受校验的JSON快照保存。部署时db-init会创建新表；不自动迁移或覆盖原采购记录。
