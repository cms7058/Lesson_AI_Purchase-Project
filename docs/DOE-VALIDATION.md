# DOE验证建设状态

## 已实现

- 多指标TOC页面、单指标回归页面和备件物料详情复用DOE组件。
- 物料档案支持生产件/备件服务端筛选；备件编辑有彩色术语及本地知识解释弹窗。
- 1至6个可控因素，两水平全因子点加至少2次中心点重复。推荐次数为2^k+2，仅为本设计下限，不是全局最小设计，不包含功效计算。用户可指定最多128次，少于本设计下限拒绝。
- 随机执行序列（固定种子可复现）、原始响应、来源说明、模拟/实际标识、模型指纹和版本冲突保护均持久化。
- 完整响应后拟合一阶主效应模型，展示执行曲线、系数、拟合值/残差、QQ图、RMSE和失拟F检验。纯误差为零或自由度不足不生成F检验结论。
- 不自动宣称验证通过；原界面“通过模型验证”改成“通过历史回测（非DOE）”。

## 不能宣称已完成

尚未将实际DOE响应映射到原TOC模型的冻结参数并完成独立预测验证；尚未设置DOE通过后才能定标的强制门禁。当前是DOE设计与数据诊断基础流程。
备件排序目前是规则模型，没有可验证的回归系数；历史质量、延期等观察指标不能直接当作可控实验因素。实际实验需业务人员确认因素、水平、约束、安全性及测量口径。
尚未实现分部因子/D最优设计、交互作用或二次模型、统计功效、复杂实验分组、实验审计审批及完整大模型术语对话。术语弹窗为明确标注的本地知识说明。
